Status: Backlog

## Summary

Add a mode where MyAI makes a plan before it changes anything.

## Expected Behavior

MyAI reads the request, shows a simple plan, and waits for approval. The user
can change the plan before work starts.

## Environment

- Product: MyAI Code Harness
- Issue: HAR-003

## Acceptance Criteria

- Enter and leave plan mode from the TUI.
- Allow reading files while planning.
- Block file changes and commands until approval.
- Save the plan and its result in the session.

## Impact

Medium. This improves control for larger tasks.
