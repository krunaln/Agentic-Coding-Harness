## Summary

Show what changed after every file change.

## Expected Behavior

The TUI shows the old and new text, the file name, and a short change summary.

## Environment

- Product: MyAI Code Harness
- Issue: HAR-008

## Acceptance Criteria

- Show diffs after create, edit, and delete actions.
- Keep the model result short.
- Show the full useful detail in the TUI.
- Make the same diff data available to future interfaces.

## Impact

High. Users need to see exactly what MyAI changed.
